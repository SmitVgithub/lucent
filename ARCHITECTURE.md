### Request Flow

```mermaid
sequenceDiagram
  actor User as 👤 User
  participant Browser as 🌐 Browser
  participant CDN as CDN Edge Node
  participant Host as Static Host

  Note over User, Host: Initial Page Load Flow
  User->>Browser: Navigate to lucent URL
  activate Browser
  Browser->>CDN: GET / (index.html)
  activate CDN
  CDN-->>CDN: Check Edge Cache
  alt Cache Hit
    CDN-->>Browser: Return Cached HTML (200 OK)
  else Cache Miss
    CDN->>Host: Fetch index.html
    activate Host
    Host-->>CDN: Return index.html
    deactivate Host
    CDN-->>Browser: Return HTML + Cache Headers
  end
  deactivate CDN

  Note over Browser, CDN: Asset Loading Flow
  Browser->>CDN: GET /styles.css
  CDN-->>Browser: Return CSS (Cached)
  Browser->>CDN: GET /main.js
  CDN-->>Browser: Return JS (Cached)
  Browser->>CDN: GET /assets/* (Images, Fonts)
  CDN-->>Browser: Return Static Assets
  deactivate Browser

  Note over User, Browser: User Interaction Flow
  User->>Browser: Scroll / Interact with Page
  activate Browser
  Browser-->>User: Smooth Animations & Transitions
  User->>Browser: Click CTA Button
  Browser-->>User: Navigate to Section / External Link
  deactivate Browser
```
